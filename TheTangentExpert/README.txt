THETANGENTEXPERT — ACTUATION.SITE
==================================

This is a static website. No database or server-side code is required.

BEFORE LAUNCH:
1. Replace hello@actuation.site with your preferred email if needed.
2. Replace the LinkedIn and GitHub placeholder links in index.html.
3. Replace project cards/text with your real project links when ready.
4. For actual donations, replace the "Support the work" mailto link with
   your preferred payment/donation page (PayPal, Ko-fi, Buy Me a Coffee,
   Stripe Payment Link, or another service available to you).

NAMECHEAP:
Upload the contents of this folder to your hosting account's public web
directory (commonly public_html). Make sure index.html is directly inside
that directory.

DOMAIN:
If you buy Namecheap Shared Hosting, follow Namecheap's instructions to
connect actuation.site to the hosting account using the nameservers supplied
by Namecheap. Do not change nameservers blindly if you are using another
hosting provider.

HTTPS:
Enable SSL in the hosting control panel and test:
https://actuation.site
https://www.actuation.site

IMPORTANT:
The domain is actuation.site, while the brand is TheTangentExpert.
That is intentional: the domain gives the brand room to evolve into
engineering/automation products later.
